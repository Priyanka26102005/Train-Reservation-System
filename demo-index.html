🚆 TrainGO

🎯 TrainGO - Complete Train Reservation System

A comprehensive Java web application built with Servlets, JSP, and MySQL for managing train reservations, user accounts, and administrative functions.

🔧 How to Run the Full Application:

1. Open Eclipse IDE

2. Import the TrainGO project

3. Configure Tomcat server

4. Set up MySQL database with name: train

5. Run on server: http://localhost:8080/TrainGO/

🛠️ Technology Stack

☕ Java Servlets 📄 JSP 🗄️ MySQL 🔗 JDBC 🎨 CSS3 ⚡ JavaScript 🐱 Tomcat

User Registration

Complete user registration system with validation and secure authentication for passengers.

Train Search & Booking

Advanced search functionality to find trains, check availability, and book tickets seamlessly.

Seat Management

Real-time seat availability tracking with 1st class and 3rd class seat selection options.

Admin Dashboard

Comprehensive admin panel for managing users, trains, schedules, and reservations.

Review System

Passenger review and rating system with CRUD operations for feedback management.

Ticket Management

Search, view, edit, and cancel ticket reservations with detailed ticket information.

Schedule Management

Complete train schedule management with create, read, update, and delete operations.

Profile Management

User profile management allowing passengers to update their personal information.

Database Integration

Robust MySQL database integration with proper connection pooling and data management.
